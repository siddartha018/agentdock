The platform Workday runs, rebuilt in the open

In a LangChain customer story, Workday describes an internal agent platform on LangGraph Agent Server: any team writes a graph and gets a deployed, governed agent. agentdock builds the same thing, piece by piece.

What Workday describesHow agentdock does it

Product teams only write the agent’s LangGraph graph.

A team adds agents/<name>/graph.py and an agent.toml. dock new scaffolds both.

Auth, security and data-retention rules come applied.

Custom Agent Server auth on every route, owner-scoped threads, PII redacted on the way in and out, and a retention sweeper.

Every agent is an MCP server and an A2A server.

The same /mcp and /a2a endpoints. Agents call each other on behalf of the user and never gain extra rights.

Tracing and evals in LangSmith.

LangSmith traces, a hash-chained audit log, and an eval gate that stops the server starting below its floor.

Prototype time fell from 4 to 5 months to under a day.

A new agent reaches a live, authenticated endpoint in 2.8 seconds.

Workday’s side is as described in the video, which gives no architecture details. agentdock’s side is measured in this repository.

Call it from Claude Code or another agent

Every agent is an MCP tool and an A2A agent. Use any key from the playground.

MCP

Adds all three agents as tools, acting as Asha (employee).

claude mcp add --transport http agentdock https://example.com/mcp --header "x-api-key: dk_dev_e100"

A2A

Sends one message to the expense agent.

curl -s https://example.com/a2a/expense_check -H "x-api-key: dk_dev_e100" -H "content-type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"message/send","params":{"message":{"role":"user","messageId":"m1","parts":[{"kind":"text","text":"$80 dinner, receipt attached"}]}}}'

This deployment runs the platform code per request on a serverless function, with Gemini 3.5 Flash-Lite on its free tier. When that tier is busy, answers fall back to the offline model and say so. The full version runs on LangGraph Agent Server with Postgres, Redis and a retention sweeper, and is live on Render (free plan, so it sleeps when idle).
